# ATLAS Stage 0 audit

This directory contains a non-structural audit of the current ATLAS codebase before any roadmap implementation work begins.

## Scope

The audit is based on the repository as it exists in this workspace and is limited to inspection, evidence gathering, and documentation. No production source files were modified.

## Canonical Stage 0 package

- [STAGE_0_CURRENT_STATE.md](STAGE_0_CURRENT_STATE.md) — a current-state report covering architecture, runtime surfaces, persistence, and user-visible workflows.
- [STAGE_0_ARCHITECTURE_MAP.md](STAGE_0_ARCHITECTURE_MAP.md) — the architecture map for the runtime layers and their interactions.
- [STAGE_0_GAP_REPORT.md](STAGE_0_GAP_REPORT.md) — the current gaps, risks, and audit conclusions.
- [STAGE_0_COMMAND_RESULTS.md](STAGE_0_COMMAND_RESULTS.md) — the verification commands that were run and their observed outcomes.
- [STAGE_0_FILE_INDEX.md](STAGE_0_FILE_INDEX.md) — a curated index of the most relevant source, config, migration, and test files.
